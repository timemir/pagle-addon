What to decide

  1. Which variant, or which parts of which ("A's list with C's set headers").
  2. Native Retail or the book? A–C are native; D borrows the Journal's language.
  3. Compact tracker: none, pinned only, or pinned + Now? Default on or off?
  4. Detail: a side pane (A), a drawer (B), expanding in place (C) or a page (D)?
  5. Sets: a filter (A), a tab (B), the main navigation (C) or bookmarks (D)?
  6. Hiding completed: mid-game, every Hunt open now has its first tier done, so Now and Soon look empty. Hide on first tier (as decided) or only once every tier is done?
